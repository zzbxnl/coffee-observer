# 咖啡产业观察

公开阅读版：百科、已发布的近一年资讯、欧美市场数据、胶囊经营研究和免费电商查询入口。

这是已发布内容快照，不包含数据库、采集后台、模型密钥或登录系统。刷新网页不会触发模型请求。网站不收集电商平台密码。电商查询导入的 CSV 仅在当前页面内存处理。研究台的观察清单、价格与五类经营记录保存在当前浏览器，可导出 JSON 后在另一台电脑导入。记录不会自动上传或发布。对应产品的官方图片均保留品牌、型号和原始出处，不能据图片推定兼容性或性能。企业目录包含 39 份去重档案，是人工维护的官方资料索引，不是实时财报数据库。

GitHub Pages：Settings → Pages → Deploy from a branch → main → /(root)。网页发布后，后续覆盖本仓库的网页和 news.json 即可更新，网址不变。
